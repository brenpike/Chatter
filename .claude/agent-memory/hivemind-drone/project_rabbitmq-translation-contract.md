`RabbitMqMessageTranslator` (internal, `src/.../RabbitMqMessageTranslator.cs`) is the ONE bidirectional translation contract all three RabbitMQ boundaries route through, replacing the per-boundary hand-rolled field mapping that drifted across ~7 prior fixes (PR #194, landed 2026-06-13). Supersedes the per-boundary halves of [[rabbitmq-header-marshaller]] and [[rabbitmq-native-prop-propagation]] (the marshaller is now the translator's header-coercion HELPER; the native-prop carry now flows through the translator's `NativeFacts`).

**Root cause it dissolves:** the adapter translated core<->AMQP at SEND/RECEIVE/REPUBLISH with NO single mapping declaration — each boundary re-decided each field's native-vs-header home + accessor, so fields drifted. The full field x boundary matrix surfaced 7 asymmetries (A TTL-not-reconstituted, B content-type-on-receive, C-family carry-only, D correlation-id dual-home, E persistence, F allowlist-decode-asymmetry).

**Field-map table (`_fieldMap`, static readonly):** descriptors for NATIVE-home fields with a core concept — each declares `coreOut` (Func<OutboundBrokeredMessage,string>), `nativeSet` (Action<BasicProperties,string>), `factsGet` (Func<NativeFacts,string>), `coreInKey`, `dualHomeHeader`:
- MessageId: native frame, no coreInKey (receiver carries id on MessageBrokerContext).
- ContentType: coreOut null (sourced by ToAmqp: stamp wins, else fallbackContentType param); coreInKey=MessageContext.ContentType (GAP B surfaced on receive).
- CorrelationId: dualHomeHeader=true (DECISION-D — native frame + header copy out); coreInKey=CorrelationId.
TTL/Expiration is a DEDICATED arm (not a string descriptor): `ResolveExpiration` floors<=0 to "0", drops TimeToLive key (marshaller already drops it); `ReconstituteTimeToLive` parses ms-string back to TimeSpan into core (GAP A, malformed/negative ignored).

**Three methods:** `ToAmqp(OutboundBrokeredMessage, fallbackContentType) -> BasicProperties` (Persistent=true hardcoded — DECISION-E); `ToCore(NativeFacts, IReadOnlyDictionary headers) -> (coreContext, deliveredContentType)`; `ToRepublishAmqp(NativeFacts, carriedHeaders, RepublishOptions{preserveExpiration, headerOverrides}) -> BasicProperties`. `CaptureFacts(IReadOnlyBasicProperties)` is the SINGLE native-capture point (Is*Present guards) — receiver calls it in BufferDeliveryAsync; `NativeFacts` (internal readonly struct) is the curated native carrier feeding both ToCore and republish.

**DECISION-B (C-family = ContentEncoding/Type/AppId/Priority/Timestamp):** captured onto NativeFacts, re-applied on republish, NEVER surfaced into core context, NEVER a new public RabbitMqMessageContext key, NEVER sourced from a core accessor on send.

**Marshaller reduction:** `_knownStringTypedKeys` -> `_stringTypedHeaderKeys` (CorrelationId + ContentType REMOVED — the translator owns them as native-frame fields; the rest of the string-typed core keys stay header-home). Added public `DecodeHeaderValue` helper the translator uses for the DUAL-HOME CorrelationId header fallback (frame absent => decode header copy byte[]->string so the core's unguarded (string) cast at InboundBrokeredMessage ctor holds).

**Receiver wiring:** `RabbitMqReceiver.FactsFrom(received)` projects ReceivedMessage's carried native fields back into NativeFacts (ReceivedMessage kept its fields, ctor unchanged). ReceiveMessageAsync: `ToCore(FactsFrom(received), received.Headers)` then strips TargetExchange/RoutingKey + stamps DeliveryTag/ChannelEpoch/InfrastructureType/ReceiveAttempts ON TOP (per [[rabbitmq-routing-leak]]). GAP B converter selection: `bodyConverterContentType = deliveredContentType ?? _rabbitOptions.MessageBodyType` then factory.CreateBodyConverter (unknown falls back to JsonBodyConverter, never throws). Republish: `ToRepublishAmqp(FactsFrom(received), received.Headers, RepublishOptions(preserveExpiration, headerOverrides))` — nack=preserveExpiration:true, deadletter:false. Sender: `ToAmqp(msg, _bodyConverter.ContentType)`; ResolveAddress kept (addressing, not field translation).

**Design-of-record:** `docs/adr/0004-rabbitmq-message-translation-contract.md` (accepted 2026-06-13) records this as the design-of-record (option iii: ONE declarative field-map table both directions all 3 boundaries; rejected per-boundary hand-rolled mapping + marshaller-only step). Closed-by-construction class eliminated = "a semantic field translated inconsistently across boundaries". ADR-0001 delivery-count stays OUT of the table (computed per-delivery, not translated). `docs/design/rabbitmq-adapter.md` §3/§5/§7 reference the contract as the single mapping surface. Integration round-trip proof: `RabbitMqRoundTripTests.SentCommandWithCustomContentTypeSelectsDeliveredConverterOnReceive` proves GAP B end-to-end against a real broker via a marker IBrokeredMessageBodyConverter keyed to a custom content-type + a singleton selection probe (converter is scoped, so observe selection through the singleton). Harness gained an optional `configureServices` Build overload + `SendToQueueWithContentTypeAsync`. CorrelationId dual-home string survival was already covered by the pre-existing TTL/header test (not duplicated).

**Test count:** RabbitMQ non-integration 192/TFM (was 161; +30 new + 1 rewritten). New file `tests/UsingRabbitMqMessageTranslator/WhenTranslatingRoundTrip.cs` pins per-field round-trip symmetry. `MustRoundTripStringHeadersThroughBoundaryToClrString` REWRITTEN to use Subject (CorrelationId is now a native-frame field, not header-decoded by the marshaller) — intent preserved. Test-double `Delivered()` builder sets native frame fields only when supplied (models Is*Present).
