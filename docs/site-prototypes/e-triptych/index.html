Chatter .NET 10

Same handlers. Any broker.

Chatter lets the same Command and Event handlers serve in-process dispatch and cross-service messaging over Azure Service Bus, RabbitMQ or SQL Server Service Broker.

One handler on three brokers

An Event drops into a queue on Azure Service Bus, RabbitMQ and SQL Server Service Broker in turn, and each column shows the same IMessageHandler<OrderPlaced> handler. Only the registration line differs: .AddAzureServiceBus(...), .AddRabbitMq(...) or .AddSqlServiceBroker(...).

Azure Service Bus

queueEvent
public class OrderPlacedHandler : IMessageHandler<OrderPlaced>
.AddAzureServiceBus(...)
=

RabbitMQ

queueEvent
public class OrderPlacedHandler : IMessageHandler<OrderPlaced>
.AddRabbitMq(...)
=

SQL Server Service Broker

queueEvent
public class OrderPlacedHandler : IMessageHandler<OrderPlaced>
.AddSqlServiceBroker(...)

Swap .AddAzureServiceBus(...) for .AddRabbitMq(...) or .AddSqlServiceBroker(...). The handler stays the same.
